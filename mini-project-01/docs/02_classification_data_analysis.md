## 1. 프로젝트 개요

### 1.1 프로젝트 목적

본 프로젝트는 온라인 쇼핑객의 웹사이트 방문 및 행동 데이터를 활용하여 고객의 구매 여부를 예측하는 이진 분류(Binary Classification) 모델을 개발하는 것을 목표로 한다.

온라인 쇼핑 세션에서 수집된 고객 행동 데이터를 분석하고, 실제 구매 여부를 나타내는 `Revenue` 변수를 예측 대상으로 설정하였다.

모델 학습에 앞서 데이터의 구조와 품질을 확인하고, 구매 여부에 따른 고객 행동 특성을 분석하였다. 이후 학습·검증·테스트 데이터 분할과 변수별 전처리를 수행하여 PyTorch 기반 Multi-Layer Perceptron(MLP) 모델에 입력할 수 있는 형태로 데이터를 변환하였다.

## 2. CP-01. 데이터 탐색 및 클래스 분포 분석

### 2.1 데이터 불러오기 및 기본 구조 확인

분석 대상 데이터는 `online_shoppers_intention.csv`이며, 전체 데이터의 크기는 다음과 같다.

원본 데이터는 총 17개의 입력 변수와 1개의 타깃 변수 `Revenue`로 구성되어 있다.

데이터를 불러온 후 `df.shape`, `df.head()`, `df.dtypes` 등을 확인하여 데이터의 크기, 샘플 구조 및 변수별 자료형을 파악하였다.

또한 실행 환경에서 PyTorch 2.15.0이 확인되었으며, 모델 학습 장치는 CPU로 설정되어 있다.

### 2.2 결측치 및 중복 데이터 확인

데이터의 품질을 확인하기 위해 전체 결측치 개수와 중복 행 개수를 확인하였다.

| 검사 항목 | 확인 결과 |
|---|---:|
| 전체 데이터 | 12,330행 |
| 결측값 | 0개 |
| 중복 행 | 125개 |

**결측치 분석**

전체 데이터에서 결측값은 발견되지 않았다.

따라서 결측값 대체(Imputation)나 결측 행 제거 작업은 필요하지 않았다.

**중복 데이터 분석**

전체 데이터에서 125개의 중복 행이 확인되었다.

동일한 특성값을 가진 데이터라도 서로 다른 방문 세션에서 발생했을 가능성이 있으므로, 중복 행을 임의로 삭제하지 않고 원본 데이터에 포함된 상태로 분석을 진행하였다.

다만 중복 행을 유지하면 동일한 특성 패턴이 서로 다른 데이터 분할에 포함될 가능성이 있으므로, 향후 모델의 일반화 성능을 해석할 때 고려해야 한다.

### 2.3 주요 수치형 변수 분포 확인

고객의 웹사이트 이용 행동과 관련된 주요 변수의 분포를 확인하기 위해 다음 4개 변수를 선정하였다.

| 변수 | 의미 |
|---|---|
| `ProductRelated` | 제품 관련 페이지 방문 수 |
| `ProductRelated_Duration` | 제품 관련 페이지 체류 시간 |
| `PageValues` | 페이지 가치 |
| `ExitRates` | 종료율 |

각 변수에 대해 히스토그램을 작성하여 값의 분포를 시각적으로 확인하였다.

**분석 목적**

- 변수별 값의 분포와 집중 구간 확인
- 고객 행동 특성의 전반적인 분포 파악
- 구매 여부에 따른 차이를 비교하기 위한 기초 자료 확보

해당 단계에서는 전체 데이터의 주요 변수 분포를 확인하였으며, 이후 CP-02에서 Train 데이터를 기준으로 구매·미구매 고객의 특성을 비교하였다.

### 2.4 타깃 변수 Revenue의 클래스 분포 분석

구매 여부에 따른 데이터 분포를 확인하기 위해 `Revenue`의 클래스별 데이터 수와 비율을 계산하였다.

| Revenue | 분류 | 데이터 수 | 비율 |
|---|---|---:|---:|
| 0 | 미구매 | 10,422 | 84.53% |
| 1 | 구매 | 1,908 | 15.47% |
| **합계** | | **12,330** | **100.00%** |

분석 결과, 전체 12,330개 세션 중 구매가 발생하지 않은 세션은 10,422개(84.53%)이며, 실제 구매가 발생한 세션은 1,908개(15.47%)로 나타났다.

즉, 미구매 클래스가 구매 클래스보다 훨씬 많은 **클래스 불균형(Class Imbalance)** 데이터이다.

#### 주요 분석 결과

1. 미구매 데이터가 전체의 84.53%를 차지한다.
2. 구매 데이터는 전체의 15.47%에 해당한다.
3. 두 클래스의 비율 차이가 크기 때문에 모델이 다수 클래스인 미구매 데이터에 편향될 가능성이 있다.
4. 따라서 Accuracy만으로 모델 성능을 평가하는 것은 적절하지 않다.

### 2.5 클래스 불균형에 따른 평가 지표 고려

클래스 불균형이 존재하는 데이터에서는 모든 데이터를 다수 클래스인 미구매(Revenue=0)로 예측하더라도 높은 Accuracy를 얻을 수 있다.

실제로 본 프로젝트의 CP-01 분석에서도 전체 데이터의 약 85%가 미구매 클래스라는 점을 확인하였다.

따라서 이후 모델 평가에서는 Accuracy뿐 아니라 다음 지표를 함께 고려해야 한다.

| 평가 지표 | 의미 |
|---|---|
| Accuracy | 전체 예측 중 정답을 맞힌 비율 |
| Precision | 구매로 예측한 데이터 중 실제 구매 데이터의 비율 |
| Recall | 실제 구매 데이터 중 구매로 올바르게 예측한 비율 |
| F1-score | Precision과 Recall의 조화평균 |

특히 본 프로젝트에서는 구매 고객을 얼마나 잘 찾아내는지가 중요하므로 Precision, Recall, F1-score를 함께 확인하는 것이 필요하다.
